week 2:
-A1 en A3 en D2 game toevoegen aan game overzichtpagina daarna valideren of alles dat liam wilt
Als Liam wil ik een korte notitie bij een game kunnen toevoegen zodat ik extra context bij de rating kan geven.
Acceptatiecriteria:


· Bij geldig invullen wordt de game toegevoegd en zichtbaar in het overzicht.
· Velden naam, platform, releasejaar en status zijn verplicht.
· Na opslaan zijn alle ingevoerde velden zichtbaar in de lijst.
· Bij poging tot dubbel toevoegen verschijnt een duidelijke foutmelding.
· Game wordt niet opgeslagen bij een duplicaat.
· Varianten met hetzelfde naam maar ander jaar mogen wel toegevoegd worden.
· Maximaal 280 tekens toegestaan.
· Afteller of melding bij overschrijden limiet.
· Notitie is zichtbaar in detailweergave.

week 3:
B1 en A2– Game bewerken

User story: Als Liam wil ik een bestaande game kunnen bewerken zodat ik informatie kan aanpassen of verbeteren.
Als Liam wil ik een status kunnen kiezen voor elke game zodat ik mijn voortgang kan bijhouden.

Prioriteit: Must Acceptatiecriteria:

· Wijzigingen worden na opslaan direct zichtbaar.
· Duplicaat-regel blijft gelden bij bewerken.
· Validatie werkt hetzelfde als bij toevoegen.
· Statusopties zijn: Wishlist / In bezit / Speelt nu / Uitgespeeld.
· Gekozen status wordt correct weergegeven in het overzicht.
· Status is filterbaar.


B2 – Game verwijderen met bevestiging

User story: Als Liam wil ik een game kunnen verwijderen met bevestiging zodat ik fouten kan corrigeren zonder per ongeluk data kwijt te raken.

Prioriteit: Must Acceptatiecriteria:

· Bij verwijderen verschijnt een bevestigingsmelding met titel + releasejaar.

· Game verdwijnt pas na bevestiging uit het overzicht.

· Annuleren houdt de game intact.
